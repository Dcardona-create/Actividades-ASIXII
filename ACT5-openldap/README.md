# ACT5 — Instalación y configuración de OpenLDAP

## Módulo

Servicios de red

## Objetivo

Instalar y configurar un servidor OpenLDAP para la gestión centralizada de usuarios, grupos y recursos de red.

## Contenido

- Instalación de OpenLDAP
- Configuración del sufijo y administrador del directorio
- Creación de unidades organizativas, usuarios y grupos
- Consultas LDAP
- Capturas y documentación de la práctica
